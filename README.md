# Bangalore Pincode Explorer

A full-stack web application built to explore Bangalore areas by pincodes. This project satisfies the internship assignment requirements using a modern tech stack and premium UI design.

## Features
- **Backend:** Node.js / Express.js REST API
- **Database:** SQLite3 (pre-seeded with Bangalore data)
- **Frontend:** React.js (Vite) with a stunning glassmorphism UI
- **Live Search:** Fast and responsive search as you type
- **Modern Aesthetics:** Vibrant colors, smooth animations, and Google Fonts

## Prerequisites
- [Node.js](https://nodejs.org/) installed on your machine.

## Getting Started

### 1. Setup Backend
Open a terminal and navigate to the `server` directory:
```bash
cd server
npm install
npm start
```
The server will start on `http://localhost:5000` and automatically seed the SQLite database with data.

### 2. Setup Frontend
Open a new terminal window and navigate to the `client` directory:
```bash
cd client
npm install
npm run dev
```
The React frontend will be available at `http://localhost:5173`. Open this URL in your browser to explore the app!

## Tech Stack
- HTML / CSS / JavaScript
- React (Frontend)
- Node.js & Express (Backend)
- SQLite3 (Database)
